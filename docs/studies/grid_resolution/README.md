# Data-free output-grid study

2026-09-08: first local 32M probe completed. No observations, GP fitting, or
posterior sampling were used. Production grid defaults have not been changed.

## Decision for the next experiment

Use `mass10` as the **provisional fixed grid**: merge adjacent pairs of the
existing logarithmic chirp-mass bins, retain the low-mass and overflow guards,
and retain dz=0.1 on 0 <= z < 1.5. This gives 58 x 15 = 870 pixels, including
guards, compared with 113 x 15 = 1695 in the current implementation.

This is a compromise for the next small-catalogue proof of principle, not a
certified resolution for LVK inference. It halves the mass cells without the
larger loss of model differences seen with four-bin merging. A choice based on
physics and model inspection can be made before observing a catalogue; proof
that the resulting parameter constraints are accurate still requires the later
direct-likelihood and noisy-mock tests.

Do not pursue a new adaptive-grid algorithm at this stage. Test this one candidate
against the native grid in the next inference pilot. If finite-population error
is unacceptable, compare targeted 512M evaluations before erasing more structure.

## What the reference paper actually used

Riley & Mandel (2023), section 2.3, use rectangular bins with nonuniform mass
widths: 0–0.5 solar masses first, then a geometric edge ratio 41/39 (5% width
relative to the bin midpoint), and an infinite overflow bin. Redshift has 15
fixed-width bins of 0.1 to 1.5. This matches the current grid construction.

- [Paper, section 2.3](https://arxiv.org/pdf/2303.00508)
- [Published DOI](https://doi.org/10.3847/1538-4357/accf90)

The candidate retains this fractional-mass-resolution reasoning. Merging two
native bins gives approximately 10% width; four gives approximately 20%.
Exact edges are generated by `configurations()` and recorded in the manifest.

## GP and sampler baseline (completed 2026-09-08)

Three sampler corrections were needed before the joint pilot:

1. Physical initial points are now transformed with NumPyro's `unconstrain_fn`.
   Previously they were interpreted as unconstrained states, so chains did not
   start at the intended physical positions. Boundary starts are avoided and
   single-chain state shape is handled separately.
2. The previous unsplit R-hat and ad hoc ESS were replaced by rank-normalized,
   folded split R-hat and bulk/tail ESS using NumPyro's diagnostic estimators.
   A single chain, constant chains or nonfinite inputs no longer look converged.
   The `converged` flag now also requires tail ESS >400 and zero divergences.
3. The unsupported `marginal` correction now raises a clear error for compressed
   or soft-clipped targets. Use `target="mean"` for the pilot. For legacy linear
   configurations the correction remains an approximation, not a validity test.

Compatibility: existing sample-file format and `ess` summary key are preserved;
`posterior_chains.npy`, `tail_ess`, diagnostic-method and initial-point fields are
added. Historical `converged` flags are not equivalent to the new criteria.
No scaler default or numerical transform has been changed. Eight combinations
of compression/soft-clipping passed NumPy/JAX inverse-transform parity tests.

The old `subset_training/test_coverage_gate.py` entrypoint now runs the corrected
baseline and no longer deletes historical coverage outputs. It performs separate
checks, not full GP-workflow SBC:

| Check | Result |
| --- | --- |
| 1,000 genuine prior/data simulations, exact Gaussian-model posterior | 68% coverage 68.3–70.7%; 95% coverage 93.1–96.0% across parameters |
| Deliberately halved posterior intervals | 68% coverage falls to 36.4–40.1% |
| Deliberately shifted posterior by one likelihood sigma | 68% coverage falls to 42.4–48.5% |
| Four-chain exact-target NUTS | maximum R-hat 1.0006; minimum bulk/tail ESS 5490/4180; zero divergences |
| NUTS posterior accuracy | means within 0.014 sigma; widths within 2% of reference |
| 1D Matérn-5/2 + sqrt GP, 61 training points | maximum CDF error 0.000108; quantile errors below 0.0001 sigma |

The baseline took 2.64 seconds excluding imports. The fast suite passed 35 tests,
with 3 heavy/network cases deselected. Diagnostic failure tests include temporal
drift and between-chain scale differences. The controls validate failure detection;
the one-dimensional GP result does not establish the difficult four-dimensional
COMPAS case, GP variance calibration or full-workflow SBC.

## Follow-up: mass cutoff and event/grid checks

The exact per-system 32M audit finds 13 selected systems above source chirp mass
40 solar masses, with a maximum of 123.293. Their fiducial detection rate is
1.5021e-5/yr (2.0591e-8 of the total). Across the eleven probes the largest
fraction is 0.02454%, at alpha=-0.5: 0.28638/yr out of 1166.90/yr. The tail's
system N_eff is only about 1–1.67 across these points. Its rate estimate is
therefore particularly fragile, despite its small size.

Decision: retain the full mass support in the likelihood and the fixed `mass10`
grid; no further coarsening now. A plotting limit near 40 is reasonable, provided
the omitted tail is acknowledged. A scientific mass-limited analysis is a
different target requiring consistent catalogue selection, measurement uncertainty,
rate normalization and model restrictions. Do not implement it as an unnoticed
array crop. The reference paper's sections 3.1.2/3.2.3 discuss rare high-mass
COMPAS systems and an explicitly restricted analysis; 40 is not a universal
upper bound on COMPAS binaries.

The next cheap validation step has also run:

- Generated a real Poisson mock at duration 0.1 yr, seed 20260908: **81 events**
  for an expectation of 72.9499. This is a perfect *binned* catalogue, generated
  and fitted using the same finite-file model, not an LVK observation.
- Aggregated exactly the same events onto all five grids. Reconstructed model
  rates agree with the directly aggregated per-system rates within 5.83e-13/yr
  per pixel across all eleven probes.
- Verified the direct count likelihood agrees with the existing one-hot event
  likelihood, including the Poisson count term and duration.
- At fixed alpha, sigma and SFR exponent, verified the SFR-amplitude posterior
  against its exact truncated-Gamma reference (shape N+1, rate
  T*R_fid/a_fid, uniform prior [0.005, 0.015]). Native and `mass10` have the same
  relative amplitude likelihood. Numerical quantiles agree within 8.13e-9 in
  amplitude units. Median 0.013146; central 68% interval [0.011862, 0.014272].
  These are conditional one-dimensional checks, not four-parameter constraints,
  GP validation, or SBC.
- Added synthetic tests of uncertain-event coefficients, including unequal bin
  areas, PE-prior division, and out-of-domain samples. This validates bookkeeping
  only; no real LVK event or selection model has been validated.

New explicit utilities are in `observation/grid_likelihood.py`. They do not

  docs/studies/grid_resolution/probe_grids.py \
  --compas-h5 tests/large_test_data/h5out_32M_reduced.h5

The output directory defaults to `results/`. Small per-parameter caches allow
repeat plotting without re-integrating when the configuration/source is unchanged.
Cache identity includes input path, size and mtime, source hashes, seed and grids;
it is not a full checksum of the large HDF5 file. Output products are ignored by
Git, so retain the script and this numerical summary for reproduction.

The loader selects all supported merging DCO types, uses the existing O3
selection approximation, and fixes seed 0. The selected 32M sample contains
83,145 systems. All five grids are constructed from each identical per-system
rate evaluation; the cosmological integration step stays 0.1.

Eleven points: fiducial (-0.325, 0.213, 0.012, 4.253), one-at-a-time minimum and
maximum of each current prior, and the all-low/all-high joint corners. These are
parameter-space probes, not a representative posterior sample or exhaustive scan.

## How to interpret the diagnostics

- Pixel N_eff = (sum system weights)^2 / sum squared system weights. For merged
  redshift cells we sum each system's contributions BEFORE squaring, preserving
  their dependence. The global value uses each system's sum over all redshifts.
- N_eff <30 is a descriptive weight-concentration threshold, not a demonstrated
  likelihood-accuracy or posterior-coverage requirement. Bins of many unequal
  weights need not behave like independent Poisson counts with mean N_eff.
- Shape separation is Jensen–Shannon divergence in nats between each normalized
  rate grid and the fiducial grid. Coarse/native ratios measure retained model
  separation for these probes. They are NOT fractions of posterior information,
  accuracy, or evidence. The smallest ratio occurs at sigma=0.1.
- Some fine-grid differences may be finite-population artifacts. Only a larger
  or independent population comparison can establish their physical robustness.
- Pure SFR-amplitude changes leave normalized shape unchanged, as expected.
  They are excluded from JS ratios where the denominator vanishes. Total-rate
  differences remain available to count-based inference at every grid size.
- Exact aggregation conserves rate (checked at 1e-12 relative tolerance).
  Empty bins remain numerically zero; no pseudocounts or smoothing are introduced.

## Physics and future LVK use

The plots retain the low-mass population, mass-dependent detection horizon,
high-mass concentration/cutoff, and changes with metallicity parameters. Fractional
mass widths allocate resolution across very different mass scales. Keeping the
native redshift bins avoids further blurring the selection horizon and already
coarse low-redshift structure. The 0.1 integration itself is not validated here.

Before calling this an LVK analysis:

1. Integrate actual event likelihood information on the chosen grid with consistent
   source/detector-frame masses, cosmology, bin densities/areas and event-prior
   correction. Do not bin posterior medians or assume a single common event error.
2. Check native-versus-candidate event integrals for narrow or unusual posteriors;
   measurement errors are event dependent, and source mass and redshift correlate.
3. Retain event samples so grid changes do not require recreating the observation
   input. Preserve explicit edges, guard bins and treatment of out-of-domain mass/z.
4. Match the selection model and observation time to the intended catalogue/run.
   The existing O3 threshold approximation is not an injection-calibrated selection
   function for an arbitrary LVK catalogue.
5. Keep population-model mismatch visible. The reference paper's section 3.2.3
   reports a posterior-predictive mismatch, including a narrow chirp-mass feature
   near 10 solar masses. Coarsening must not be used to conceal that discrepancy.

Chart contract: static Matplotlib scientific figures, blue sequential maps,
blue/orange/neutral comparison curves with line-style distinctions, logarithmic
mass axes, identical scales for comparable maps, white unsupported cells. Figures
